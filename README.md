# Netflix Data Analysis Project

This project focuses on analyzing the Netflix Titles Dataset using Python libraries such as Pandas and Matplotlib.

## Objectives

* Understand the structure of the dataset
* Clean missing values
* Perform exploratory data analysis (EDA)
* Analyze Netflix content trends
* Create visualizations for better understanding

## Tasks Performed

* Loaded and explored the dataset
* Checked missing values using `isnull()`
* Filled missing values using `fillna()`
* Filtered data using conditions
* Used grouping and counting functions
* Found top countries and release years
* Analyzed ratings and content types
* Created bar charts, pie charts, and histograms

## Key Insights

* Movies are more common than TV Shows on Netflix
* TV-MA is one of the most common ratings
* Most Netflix content was added after 2018
* Some countries contribute more content than others
* Release trends increased significantly in recent years
